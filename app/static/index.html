What it does

01Drop-in

Works with the OpenAI SDKs and anything that calls /v1/chat/completions. Swap the base URL and the key.

02Fallback

If a model keeps failing after retries, the request is tried on the other model. Your app gets an answer instead of an outage.

03Cache

Identical requests are answered from memory at no cost. Caches are never shared between keys.

04Keys and limits

Each customer gets their own key, a monthly quota and a per-minute rate limit. GET /v1/usage shows what has been used.

05Optional routing

With model: "auto", simple rules send short, plain prompts to a smaller model. Send "cheap" or "strong" to choose yourself.

Quickstart

from openai import OpenAI

client = OpenAI(
    base_url="https://llm-routing.onrender.com/v1",
    api_key="gw_your_key",
)

r = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "Hello"}],
)
print(r.choices[0].message.content)
curl https://llm-routing.onrender.com/v1/chat/completions \
  -H "Authorization: Bearer gw_your_key" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello"}]}'

Each response includes a gateway block with the route taken, the cost and whether it was cached.

Limits, stated plainly

  • Text messages only. No images.
  • No streaming yet. stream: true returns an error.
  • Temperature is fixed at 0.
  • Prompts up to 8,000 characters.
  • 20 requests per minute per key by default.
  • Use max_tokens of 200 or more. The models spend some output on reasoning.
